# GPT Query

GPT Query is a Python library to query OpenAI's GPT-4 model

## Usage: 

```
from gpt-query import GPTQuery

gpt_query = GPTQuery()
prompt = "What is the main activity sector of Tesla, Inc.?"
response = gpt_query.query(prompt)
print(response)
```
