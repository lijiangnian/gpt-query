# v0.3.0 验收说明

- 新增 Qwen3-ASR 文件转写与豆包录音文件 ASR。
- 新增连接测试、真实错误码/LogID 展示和加密凭证设置。
- 新增自动主引擎、备用切换、实际引擎记录和默认关闭的付费保护。
- 每次结果另存 TXT、SRT、alignment JSON；词级时间戳可用时写入 words。
- 硬字幕截图包升级为 v2 manifest：segment ID、锚点、±2 秒/250ms 扩展搜索、去重。
- 删除 App 内双稿 Gemini API 校对类、界面、网络入口和相关 APK 字符串。
- Gemini 作为独立 ASR 引擎保留。

正式云端音频调用必须由用户在真机设置有效凭证后执行。开发构建不包含也不读取用户凭证。
