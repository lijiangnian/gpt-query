# MediaParser v0.4.4

## 本版改动

- 六引擎横评页支持导入 UTF-8 TXT / SRT 标准稿，文件上限 2MB。
- CER 计算统一中文数字与阿拉伯数字写法，避免“12800”和“一万二千八百”被误判为大量错字。
- 保留专名、人名、英文模型名和真实识别错误，不用宽松规则虚增准确率。
- 修复小红书 Live Photo 静态图下载 403：保留 CDN 签名变换后缀。
- 开发者说明加入真实准确率、时间戳、耗时和综合排名，并明确单样本结果的适用范围。

## 页面结构

1. **直连解析**：抖音、小红书、快手、B站、微博。
2. **本地处理**：本地视频/音频、字幕、逐字稿、会议、六引擎横评。
3. **更多**：API 设置、本地模型管理、开发者说明与历史任务。

API Key、Token 等凭证由用户填写并经 Android Keystore 加密保存在本机，不写入 APK、日志、导出文件或截图 ZIP。
