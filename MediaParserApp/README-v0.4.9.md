# MediaParser v0.4.9

本版修复抖音商城商品分享链接被误当作普通抖音作品、最终提示“页面未返回可解析数据”的问题。

## 修复内容

- 识别 `v.douyin.com` 跳转后的抖音商城商品详情页。
- 使用本机 WebView 获取商品页的临时签名，不上传账号或浏览器数据。
- 兼容抖音把商品接口放入 WebWorker 的页面结构。
- 当接口正文无法直接读取时，自动触发页面公开的商品主视频并捕获真实播放地址。
- 返回商品主视频、商品封面和可提取的完整音轨；接口响应可读时同时返回商品图片列表与店铺名称。
- API 路径与目标域名均有白名单校验，不接受任意页面发起代理请求。
