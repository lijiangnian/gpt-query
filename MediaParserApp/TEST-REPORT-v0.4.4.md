## 小红书 Live Photo 修复

测试笔记解析得到 4 张 IMAGE 与 1 个 Live Photo VIDEO。修复前静态图 URL 因移除 CDN 的 `!nd_...` 签名变换后缀返回 HTTP 403；修复后保留完整 URL，4 张图片和 1 个视频全部返回 HTTP 206（5/5）。新增 `XhsParserTest` 防止回归。

## 范围说明

平台页面、临时直链和服务商 API 会变化。HTTP 206 证明测试时可读取媒体内容，不承诺链接永久有效。端到端耗时包含下载/上传、网络、排队、推理和返回；豆包较慢不等同于模型本身纯推理较慢。
