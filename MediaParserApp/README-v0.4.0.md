# MediaParser v0.4.0

本版把原有社媒字幕工具扩展为本地音视频与会议转写工作台。

## 新功能

- 首页新增“选择本地视频”“选择本地音频”“会议 / 录音”入口。
- 支持 Storage Access Framework，长期保留用户授权的本地文件读取权限，不要求先上传社媒平台。
- 字幕与会议共用 `mediaparser-asr-v2` 统一结构。
- 会议模式请求支持该能力的引擎返回说话人信息；Paraformer-v2 在会议模式开启官方 `diarization_enabled`。
- 六引擎横评逐个运行并独立显示状态，避免多个云端任务混成一个进度。
- 横评报告保存实际引擎、耗时、分段数和时间轴覆盖率；只有提供参考稿时才计算 CER、漏字率与时间戳误差。
- 新增转写编辑器：编辑、播放、合并、拆分、删除和重新导出。
- 视频编辑页可继续制作按 ASR 时间轴定位、锚点失败才扩展 ±2 秒/250ms 搜索的硬字幕截图包。
- 会议纪要与字幕整理继续采用“复制/导出 → 网页版模型”的方式，不恢复 App 内 Gemini 二次校正。

## 本地文件与云端

- Gemini、Groq：App 直接上传准备后的音频。
- 豆包：本地文件使用 App ID + Access Token 的流式小时版直传。
- 阿里 Paraformer/Qwen3-ASR：上传到阿里百炼官方临时 OSS；文件与账号及模型绑定，48 小时自动清理。App 在模型请求中加入官方要求的 `X-DashScope-OssResourceResolve: enable`。
- 本地模型：音频不离开手机。

所有云端调用仍受默认关闭的单任务授权开关保护。
