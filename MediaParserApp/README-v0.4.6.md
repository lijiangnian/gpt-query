# MediaParser v0.4.6

v0.4.6 在原有社媒解析、本地音视频、会议模式、六引擎横评、时间轴编辑器和硬字幕截图 ZIP 之外，新增知乎任意复制与 OpenList / AList 网盘媒体直链。原有 ASR 和解析方式均保留。

## 四个主页

- **直连解析**：抖音、小红书、快手、B站、微博、知乎，以及普通 HTTPS 媒体直链。
- **网盘直链**：识别国内网盘分享文案，或连接用户自己的 OpenList / AList 获取已授权文件的临时源站直链。
- **本地处理**：导入视频、音频和会议录音，生成字幕、逐字稿、会议整理包或六引擎横评。
- **API 设置**：凭证、鉴权、全面测试和开发者说明集中在子页面，不占用主流程。

## 知乎任意复制

以下输入都可以直接接收：

- 知乎 App 的完整分享文案；
- 文章、回答、问题、视频的 HTTPS 链接；
- 文案里的无协议 `zhihu.com/...` 链接；
- Android 系统“分享”和“处理文本”；
- 没有链接的纯复制文字。

公开页面可直接提取标题、作者、正文、封面和媒体。遇到登录墙或验证页时使用本机 WebView；Cookie 只保存在 Android WebView。回答已删除或没有正文时，App 保留网页让用户处理，不会把知乎站点通用介绍当成正文。

## OpenList 网盘直链

MediaParser 不破解网盘，也不绕过登录、会员、提取码或防盗链。推荐流程：

1. 用户在自己的 OpenList / AList 中完成 115、阿里云盘、夸克、百度、天翼、移动云盘等存储授权。
2. 在 App 配置 HTTPS OpenList 地址，并选择 Token 或用户名/密码登录。
3. 输入 OpenList 内部文件路径，App 调用 `/api/fs/get` 获取临时 `raw_url`。
4. 临时源站直链可直接保存、提取音频或进入字幕流程；`/d/` 地址保留为备用。

App 保留 OpenList 返回的 User-Agent 和 Referer，以兼容 115 等绑定请求头的临时地址；Authorization 请求头会被过滤，不传给下载器、播放器或导出文件。服务器、Token、用户名和密码由 Android Keystore AES-GCM 加密。只允许 HTTPS OpenList。

普通网盘分享文案目前支持识别 115、阿里云盘、夸克、百度网盘、天翼云盘、中国移动云盘和腾讯微云，并提取常见“提取码 / 访问码 / 密码 / 口令”。分享页会引导用户先到官方页面保存/授权，不会被错误当作媒体文件。

## API 与费用

原有 Gemini、Groq、阿里 Paraformer-v2、Qwen3-ASR、豆包/火山 ASR 和本地 sherpa-onnx 均保留。免费额度、试用额度、参考价格、凭证获取步骤、豆包 Resource ID 注意事项和两条真实样本的准确率排序，均在 App 的“API 设置 → 开发者说明”中查看。价格核对日期为 2026-08-30，最终以服务商控制台为准。

## 凭证安全

- 正式 APK 没有凭证迁移 Activity。
- 完整 API Key、Token、Secret、OpenList 凭证不会写入源码、APK、日志、字幕、JSON、诊断报告或截图 ZIP。
- API 全面测试默认只做鉴权，不上传媒体；真实转写必须用户主动导入文件并勾选。
- 云端付费许可默认关闭。
