# MediaParser v0.1.15：截图辅助校对与独立进度

## 使用

选择“Gemini + Groq → Gemini校对”，展开“识别设置”，勾选“双模型校对时参考画面字幕”，保存设置，再生成字幕。默认不开启截图；单模型路线不上传截图。API Key 设置仍位于页面底部并默认折叠。

依次执行 Groq、Gemini、Gemini 校对，三项分别显示状态，上传显示真实字节进度；云端识别没有真实百分比时只显示等待时间。一家失败仍尝试另一家，原稿保留；校对失败明确显示未生成，可只重试校对。

正文上方可切换 Gemini 原稿、Groq 原稿、校对建议稿。修改/待复听记录可直接查看。SRT、TXT 另存，不覆盖原稿。双模型优先采用 Groq 字级时间，Groq 不可用时才采用经校验的 Gemini 时间；都没有时只输出文字，不估算 SRT。

## 截图与配额

从已经下载的视频中本地抽帧，不再次下载视频；最多60张，每批最多16张，图片长边最多960像素。短视频约每2秒一帧，长视频稀疏抽样，可能漏掉字幕。取帧失败或纯音频来源会明确说明校对只用文字。只把抽样截图与转写稿交给 Gemini 3.1 Flash-Lite；不会把截图发给 Groq 或语音转写接口。

官方标准免费层包含该模型的图片输入和文字输出，但仍受项目额度限制；不保证永久免费或无限调用。免费层数据可能用于产品改进。

- https://ai.google.dev/gemini-api/docs/pricing#gemini-3.1-flash-lite
- https://ai.google.dev/api/interactions-api

画面文字可能是标题、广告、弹幕，也可能自身有错。校对要求忽略这些内容，只参考对白/歌词字幕。启用画面参考后，受限幅度的修改会显示为校对建议，大幅改动或否定词变化标记待复听；数字变化和极端改写仍保护性保留。原稿始终单独保留。

## 时间轴防护

拒绝超出实际媒体时长、倒置、最终零时长、乱序/重叠及异常长字级锚点。无效时间保留文字但不导出 SRT，不通过除以100、截断到片尾等办法伪造修复。校验通过仅代表数值和顺序合理，不代表已经与声音逐字对齐。截图取帧时间不作为字幕起止时间。
