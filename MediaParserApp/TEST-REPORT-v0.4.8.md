# MediaParser v0.4.8 测试报告

## 验收重点

- 真实抖音商城纯口令能够识别标题、口令和商品类型。
- 纯口令不会被误报为普通文本或已提取视频。
- 一键复制口令并打开抖音；返回链接后可以继续解析。
- 公开精选商品视频页可得到真实视频与完整音轨。
- 选择 Android 兼容的 H.264 清晰版本。
- 原有解析、字幕、本地处理、会议、网盘和 API 功能不被删除。

## 本次结果

- 开发设备：`emulator-5554`，Android 16 / API 36，1080×2400。
- 真实口令：`【立式水龙头置物架…】…查看商品详情##jdfvc5ael99##`，成功识别完整商品标题与口令，页面显示“复制口令并打开抖音 / 粘贴链接继续”。
- 公开精选页：`https://jingxuan.douyin.com/m/video/7645320368391856377`，成功解析为“抖音商城视频”，得到主视频与 M4A 音轨两个媒体项。
- 清晰度选择：从九个视频变体中选择 H.264 720p normal 兼容版本。
- 下载探测：对提取直链请求 `Range: bytes=0-1023`，返回 `HTTP 206`、`Content-Type: video/mp4` 和 1024 字节真实媒体数据。
- JVM 单元测试：47 项通过，0 失败，0 错误。
- 模拟器覆盖安装成功，原应用数据未清除；界面无崩溃。
