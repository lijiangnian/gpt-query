# MediaParser v0.4.3 测试报告

测试设备：Xiaomi 13（2211133C / fuxi），Android 16，arm64-v8a。

## 准确率测评规则

- 没有参考稿：CER、漏字率、时间戳误差、准确率排名均不可用。
- 纯文本参考稿：计算文字准确率、CER、漏字率；时间戳权重不参与并重新归一化。
- SRT 参考稿：同时计算文字指标与平均时间戳误差。
- 报告分别输出“文字准确率排名”“综合排名”和“端到端耗时排序”。
- 端到端耗时明确包含网络与链接影响，不宣称为模型纯推理速度。

## 自动化检查

- Gradle：`testReleaseUnitTest assembleRelease lintRelease` 成功。
- 单元测试：21 项，0 failures，0 errors。
- APK v2 签名校验通过。
- 完全一致的参考文稿得到 100% 文字准确率。
- 没有参考稿时拒绝生成 CER 和综合分。
- 纯文本参考稿缺少时间轴时，综合分不会因缺失指标被扣 30 分。
- TXT/JSON 报告保留原始指标和排名依据。
