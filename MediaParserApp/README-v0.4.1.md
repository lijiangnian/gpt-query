# MediaParser v0.4.1：一键 API 与六引擎测试

本版新增手机端“API 与整机一键测试”。完整 API Key、Access Token 继续由 Android Keystore 加密保存，测试过程不导出原始密钥。

## 一键测试

- 默认逐项测试 Gemini、Groq、阿里云 Paraformer/Qwen3-ASR、豆包/火山的鉴权与模型权限。
- 显示掩码、实际状态、耗时和服务端脱敏错误。
- 检查 SenseVoice、Fun-ASR-Nano、Paraformer 本地模型是否安装并通过文件校验。
- 可复用最近导入的本地音视频，自动依次执行六个 ASR 引擎。
- 真实转写会检查实际引擎、耗时、分段数、句级时间轴顺序和词级时间戳数量。
- 测试报告可复制或保存到系统 Download；报告不包含完整 Key / Token。

## 付费保护

默认测试只做鉴权，不上传媒体。真实转写必须由用户主动勾选“可能耗费额度”的开关。服务商没有正式余额查询接口时，App 明确提示到控制台查看，不猜测余额。

## 横评评分

提供真实参考稿时，综合分采用：文字准确率 40%、时间戳准确度 30%、漏句 15%、速度 10%、稳定性 5%。没有参考稿时不生成 CER、漏字率、时间戳误差或综合分。

## 安全说明

App 不提供“导出所有 API Key”功能。Android Keystore 的目的就是阻止密钥被批量导出。迁移设备时应在服务商控制台重新生成密钥，而不是复制旧密钥。
