# MediaParser v0.4.5

v0.4.5 重点处理云端 ASR 的实际可用性、时间轴安全和本地文件速度。APP 保留直连解析、本地音视频、会议模式、六引擎横评、截图 ZIP、编辑器和原有 API，不再调用 Gemini API 做二次校对。

## 页面结构

- **直连解析**：抖音、小红书、快手、B站、微博的公开分享链接。
- **本地处理**：导入 MP4 / MOV / MKV / MP3 / M4A / WAV / AAC，生成字幕、逐字稿或会议整理包。
- **API 设置**：凭证、鉴权、全面测试和开发者说明都放在子页面。

## v0.4.5 变化

- 豆包极速版资源 `volc.bigasr.auc_turbo`：本地音频使用官方 flash 单请求 Base64 上传，不依赖公网直链；APP 对直接上传采用 20MB 稳定上限，超限或失败自动切换 4 倍速流式。
- 豆包标准版仍支持公网 URL；遇到抖音防盗链或本地文件会回退流式，不因一个接口失败丢掉整个任务。
- Gemini / Groq 时间戳加入按真实音频时长的边界校验。允许修复小范围回退和尾部越界，明显乱序仍会拒绝。Groq 词级时间戳异常时改用服务端句级时间轴。
- 编辑器数据放到 APP 内部目录，并在真正退出后清理，避免小米系统旋转或重建页面造成 `ENOENT`。
- 横评文本即使没有合格时间轴也保留全文并计算文字准确率，不再把有效文本错误计为 0%。
- 小红书 Live Photo 保留 `!nd_...` 签名后缀，修复静态图片 HTTP 403。

## 真实样本结论

测试设备：Xiaomi 13。中文样本为 3 分 48 秒动物解说，英文样本为 27.8 秒采访，均使用人工复核稿。

| 引擎 | 中文准确率 | 英文准确率 | 中文端到端耗时 |
|---|---:|---:|---:|
| 豆包极速版 | 97.1% | 93.9% | 约 8.6s |
| Qwen3-ASR | 96.1% | 100.0% | 11.6s |
| Paraformer-v2 | 93.2% | 98.8% | 15.6s |
| Gemini | 90.2% | 96.3% | 19.9s |
| Groq Whisper | 89.6% | 100.0% | 20.4s |
| 本地 Fun-ASR-Nano | 87.7% | 94.1% | 25.0s |

排名只代表这两条样本。歌曲、多人会议、方言、混响和强噪声必须另建测试集。

## 凭证安全

API Key、Token 由用户填写，并使用 Android Keystore AES-GCM 加密保存在手机。凭证不会写入 APK、日志、字幕、对齐 JSON、诊断报告或截图 ZIP。云端调用仍要求用户对当前任务勾选许可。
