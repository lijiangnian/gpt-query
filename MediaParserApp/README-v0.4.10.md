# MediaParser v0.4.10

本版修复抖音商城商品解析在部分小米 / HyperOS WebView 上停留于“读取商品媒体”的问题。

- 商品页加载后自动寻找并触发商品视频，不再要求用户手动点播放。
- 兼容不同商品页 DOM 样式，并在页面异步渲染期间每 500ms 重试，最多 10 秒。
- 使用 WebView 原生触摸事件触发播放，兼容要求真实用户手势的 Android WebView。
- “重新读取商品媒体”改为直接重新尝试读取，避免无意义的整页刷新。
- 保留 v0.4.9 的商品主视频、封面和完整音轨输出。

测试链接：`https://v.douyin.com/KS49Ifpjl8c/`

验证结果：Android 16 模拟器中，商品页自动打开后自动返回，解析得到 3 个媒体文件。
