# MediaParser v0.4.8

本版在 v0.4.7 上新增抖音商城商品口令与精选商品视频提取，原有直连解析、知乎编辑器、网盘直链、本地音视频、会议模式、ASR 和 API 设置全部保留。

## 抖音商城口令

- 识别包含 `##…##` 与“查看商品详情”的抖音商城分享口令。
- 展示商品标题与脱敏口令，不再把它当成普通复制文本。
- 一键复制完整口令并打开抖音。
- 商品页还原后，可把商品主视频分享回 MediaParser，继续提取、保存或生成字幕。
- 从抖音返回后，如果剪贴板已有有效链接，App 自动继续解析；也可手动点“粘贴链接继续”。

商城口令是抖音 App 内部交换格式，本身不包含公开视频 ID。MediaParser 不使用来路不明的付费解析站，也不会绕过登录、会员、地区或商品访问权限。

## 精选商品视频

- 支持公开 `jingxuan.douyin.com/m/video/{id}` 页面。
- 从页面 SSR 数据读取标题、作者、说明、封面和视频列表。
- 优先选择 Android 兼容的 H.264 清晰版本。
- 输出商品主视频直链与可无损封装为 M4A 的完整音轨。
- 商品只有图文、视频已下架或页面要求登录时显示真实原因，不虚构成功。
