# MediaParser v0.1.13 — 识别参数与 AE86 字幕拼接

本版继续调整现有 Android App，不做115网盘或实时插件。

## 已完成

- Gemini / Groq 手动双路线保留，不自动跨服务上传音频。
- 增加默认收起的“识别设置”：自动语言 / 中文（普通话）、Groq Large V3 / Turbo、可选术语。
- Groq 默认从 Turbo 改为 Large V3；语言默认仍自动，术语默认空白，不给所有视频强加动物词表。
- 设置需点击保存，下次生成生效；任务开始时固定参数，运行中不能保存或切换路线。
- Groq 发送 language / prompt；Gemini 发送 language_codes / custom_vocabulary，保持 verbatim + word 时间戳。
- 术语最多20个、合计UTF-8不超过200字节，支持中英文逗号、顿号、分号及换行；拒绝控制字符。
- 修复 Groq 字级时间戳将 AE86 拆成 A / E / 86 后，App 输出为 A E 86 的问题。
  只有字级文本与接口全文严格对齐，且全文证明中间没有空格时，才合并相邻字母/数字；保留真实起止时间。
  如果全文识别成 A186，App 不会擅自改为 AE86；如果全文有空格，也不会删除。
- 时间轴预览、复制完整SRT、全文切换和底部默认收起的API Key设置保留。
- 仍只有 INTERNET 权限，没有本地Whisper模型、录音权限、悬浮窗或后台服务权限。

### 不能声称“整篇准确”

- 用户原Gemini结果里反复出现“鬣豹”；这次Groq两种Large V3配置识别到了“猎豹”和“陆地”。
- 但“CP→嬉皮”“惯性→关力”“鬣狗→猎狗”等仍有错误；开头/背景台词也需逐句复听。
- 第三组把“善有善报”输出成“善有善豹”，说明术语可能引入偏差；所以词表默认空白，不做全局替换。
- 开头画面自带字幕与ASR首句也有差异。没有人工逐字校对全片，不报告整体准确率或WER。
- 交付的SRT/TXT标记为“待校对”，不是人工校正版。不同模型、同一模型不同运行都可能有不同结果。
- 本轮Gemini新增语言/术语参数通过官方格式核查与请求构造测试，尚未在这条原视频上重新实测Gemini。
- 初次独立Python测试收到HTTP403/error1010，未取得转写；该失败记录保留。随后实际App客户端三组测试成功。
  因此不把Python请求失败等同于Key失效，也不声称所有手机网络都可达。

## 使用

1. 安装新版；保留原Key即可。API设置仍在页面最下面，默认收起。
2. 选Groq路线；“识别设置”默认Large V3，可先不填术语生成一遍。
3. 已知普通话视频可选中文；特殊拼写可少量加入术语，例如AE86。其他视频记得调整或清空，并点击保存。
4. 仍需校对字幕，尤其电影台词、谐音梗、方言、背景人声和专有名词。

语言与词表提示依据 [Gemini官方文档](https://ai.google.dev/gemini-api/docs/transcribe) 和 [Groq官方语音文档](https://console.groq.com/docs/speech-to-text)。
提示不保证准确；设置不改变所用账户的Free/Paid层级，也不承诺固定免费额度。
