# MediaParser v0.3.5

本版修复 Qwen3-ASR 只返回少量句子却被 APP 当作完整成功的问题。

- 从百炼结果的 `properties.original_duration_in_milliseconds` 读取原始音频总时长，不再用最后一句的结束时间冒充总时长。
- 对片段数、文字量以及首尾时间覆盖进行保守检查；疑似漏识别时显示“识别覆盖率异常”。
- 手动选择 Qwen3-ASR 时仍保存 TXT、SRT 和 alignment JSON 原稿，但显示警告，不擅自发起第二次可能收费的调用。
- 自动选择模式遇到 Qwen3-ASR 低覆盖结果时，保留该原稿并继续已获授权的备用引擎；备用都不可用时返回保留稿，不让整个任务无结果。
- 百炼返回的 channel 级全文比 sentences 更完整时，TXT 保留完整全文；SRT 仍只使用服务端真实时间戳，不伪造时间轴。
- 保留 v0.3.4 的结果地址安全修复、豆包流式直传回退、本地模型及其他全部现有功能。

“低覆盖”属于质量告警，不能证明遗漏内容，也不会凭空修复服务商已经漏掉的歌词。歌曲或强伴奏视频建议使用自动选择、本地模型或硬字幕截图 ZIP 进行交叉校对。
