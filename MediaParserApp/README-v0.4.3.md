# MediaParser v0.4.3：准确率横评

## 测评不再只看速度

- 全面测试页新增“标准答案”输入，支持人工文稿、硬字幕 OCR 文本和 SRT。
- 有标准答案时显示文字准确率、CER、漏字率，并生成文字准确率排名。
- 参考 SRT 带时间轴时，额外计算平均时间戳误差。
- 综合排名权重：文字 40%、时间戳 30%、漏字 15%、端到端耗时 10%、稳定性 5%。参考稿没有时间轴时会对可用指标重新归一化，不会把缺失的时间戳指标算成零分。
- 没有标准答案时不生成准确率或综合排名，防止把模型一致度误当正确答案。

## 耗时口径

报告中的耗时改称“端到端耗时”，包含音频准备、直链下载或上传、网络、服务端排队、模型推理与结果返回。豆包等服务可能受源链接可达性和流式直传回退影响，端到端耗时不等于模型纯推理速度。

严格速度横评应使用同一本地文件、同一网络环境，重复多轮后比较中位数。
