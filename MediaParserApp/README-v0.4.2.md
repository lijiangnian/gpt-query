# MediaParser v0.4.2：三页架构与 ADB 真机验收

API 设置页新增“开发者说明 · API 获取与使用帮助”子页面，包含直连解析、本地处理、API 配置、额度与计费、隐私安全、错误排查、六引擎真机排序和测试方法，并由开发者 `lijiangnian` 署名。关于页显示抖音昵称 `ljn`、抖音号 `70258976876`，可通过本人主页分享链接直达。

## 页面层级

- **直连解析**：社媒分享链接解析、保存视频、字幕生成。
- **本地处理**：本地视频/音频、会议模式、六引擎横评。
- **API 设置**：Gemini、Groq、阿里、豆包凭证配置；完整设置表单不再堆在直连主页。
- **分页测试报告**：API 设置下的次级页面，报告支持上一页/下一页。

三个页面统一处理状态栏安全边距。ADB 真机测试曾发现本地页导航压入状态栏，现已修复。

## 一键全面测试

默认执行不上传媒体的鉴权测试。主动勾选真实转写后，自动复用最近导入的文件依次测试本地、Paraformer、Qwen3-ASR、豆包、Gemini、Groq，并检查分段、句级时间轴和词级时间戳。

## Qwen3-ASR 修复

修复 OSS 签名结果地址从 HTTP 升级 HTTPS 时查询参数被重新编码，导致 `SignatureDoesNotMatch` 的问题。现在只替换协议前缀，完整保留签名路径与查询字符串。

## 安全

- API Key / Token 继续使用 Android Keystore 加密保存。
- 测试报告、日志、字幕文件和截图 ZIP 均不包含完整凭证。
- 真实云端转写仍需主动许可，避免未经允许消耗额度。
