# MediaParser v0.3.7

本版修复本地 ASR 输出固定约 25 秒一条、不能直接作为字幕时间轴的问题。

- 本地识别首次使用时下载并校验约 629KB 的 Silero VAD 分句组件，不写入 APK。
- 按真实语音活动切段，连续配乐场景最长约 12 秒强制重新分段，不再机械生成 25 秒大块。
- 优先读取 sherpa-onnx 模型返回的 token 时间戳，并按标点和字幕长度生成短句。
- 模型没有有效 token 时间戳时，仅在真实 VAD 语音片段内部按文字长度细分，并在结果中明确提示。
- 每条字幕限制为约 22 个字符，长句优先在逗号、顿号、冒号或空格处断开。
- Silero VAD 下载失败时自动回退旧的能量检测，本地任务不会因此整体失败。
- 保留 v0.3.6 的模型下载百分比、速度、预计剩余时间、断点续传和 SHA-256 校验。

验证：6 项 JVM 单元测试、Android Release 编译和 lintVitalRelease 均通过。由于当前电脑没有连接 Android 真机，Silero JNI 与本地 ASR 的整段实测需要安装后在小米 13 上跑同一个视频确认。
